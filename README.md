# Huazhong University of Science and Technology (HUST): Space Communication Systems Experiment Design

华中科技大学空间通信系统实验设计课程实验代码与仿真结果。

## Experiments

- [伪码生成与相关特性仿真](伪码生成MATLAB仿真/README.md)：根据 10 级 LFSR 生成 m 序列，并计算周期自相关、互相关。
- [延迟锁定环 DLL 仿真](延迟锁定环DLL仿真/README.md)：仿真 PRN 20 相关输出、多普勒失配、三种码相位鉴别器及噪声影响。

每项实验独立存放在一个目录中，目录内包含 MATLAB 脚本、运行结果、图表和实验说明。
